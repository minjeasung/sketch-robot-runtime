# H형강 평면 추출

`target_selector`는 `plane_structure=hbeam`을 기본값으로 사용한다.
시작 시 ROS 파라미터 `plane_structure=generic`으로 일반 평면 모드를 선택할 수 있다.
예: `ros2 run sketch_control target_selector --ros-args -p plane_structure:=generic`.
이 파라미터는 노드 시작 시 읽으므로 변경 후 노드를 다시 시작해야 한다.

## 처리 순서

1. 깊이의 연결 영역에서 RANSAC으로 면을 찾는다. RGB 경계로 RANSAC 입력을 먼저 나누지 않는다.
2. 3×3, 5×5 깊이 이웃의 법선으로 좁은 web/flange 후보를 보완한다. 모든 후보는 측정된 깊이 점으로 검증한다.
3. 원래 점을 후보 면까지의 거리로 공동 배정하고, 연결성·최소 면적·최소 폭을 검사한다. 급경사 면은 인접한 역깊이 변화가 이어지면 연결하고, 실제 깊이 단절은 분리한다.
4. H형강 모드는 비슷한 방향의 짧은 잔여 조각을 억제한다. 남은 면의 원래 지지점은 유지하면서, 탈락한 후보가 차지하던 점을 다시 배정한다. 기존 면의 점을 서로 빼앗지 않으므로 좁은 면이 무너지거나 지지점이 중복되지 않는다.
5. 마지막으로 RGB 직선 경계가 이미 확인된 두 면 사이에 있을 때만 모호한 점의 소속을 보정한다. 경계에서 최대 두 샘플 간격(기본 8px), 두 모델 모두의 거리 허용 오차 안, 잔차 차이가 최대 2mm인 점만 이동한다. 면 개수·법선·평면 위치는 바꾸지 않으며 연결성이나 최소 면적을 깨뜨리면 깊이 기반 배정을 유지한다. RGB와 깊이의 시각·해상도가 맞지 않으면 이 단계는 생략한다.

일반 모드는 깊이 기반 후보 생성과 마지막 RGB 보정을 공유하며, H형강 전용 잔여 조각 억제와 지지점 복원은 적용하지 않는다.
카탈로그에는 `structure`, `extraction_version=geometry_first_v2`,
`extraction_method=depth_ransac` 또는 `depth_ransac_rgb_refined`를 기록한다.
면별 `interior_support_ratio`와 `interior_rms_m`는 선별 전 내부 깊이의 기하적 일관성이다.
윤곽의 한 샘플 띠와 별도 깊이 연결 영역은 제외하고, RANSAC이 탈락시킨 점도 포함한다.
내부 점이 너무 적으면 `null`이며, 센서 신뢰도나 절대 정확도를 뜻하지 않는다.
내부 점의 80% 미만이 평면 허용 오차에 들어오면 `depth_consistency_warning=true`를 기록하고
화면에 ‘깊이 일치 부족’을 표시한다. 얕은 가림 물체도 이 점수를 낮출 수 있으므로 자동 삭제 기준으로 사용하지 않는다.

## 검증과 한계

합성 테스트는 알려진 형상을 기준으로 폭 16/24px web, 회전, 근거리,
부분 가림, 급경사 flange, 짧은 끝면, 평행 단차, 깊이 잡음을 검증한다.
같은 깊이에 그림자의 위치와 밝기만 바꿔도 면이 나뉘거나 3D 모델이 이동하지 않는지 검사한다.
RGB 보정은 실제로 모호한 경계 점을 이동시키는 경우와, 연결된 면을 끊어서는 안 되는 경우를 함께 검사한다.
선택 콜백 통합 테스트는 같은 계약과 카탈로그 버전을 확인한다.

기존 12프레임 녹화는 RGB 변화에 대한 일관성을 검사한다. 예전의 ‘네 면’ 기대값은
사용자가 잘못된 분리라고 확인한 영상 해석에 의존했으므로 정답으로 사용하지 않는다.
별도 3프레임 회귀 데이터는 사용자가 지적한 면 1·5의 영역에서도 RGB가 3D 모델을 바꾸지 않으며,
선별 전 깊이의 불일치가 진단에 드러나는지 검사한다. 전체 장면의 정답 면 개수나 보정된 3D 치수를 제공하는 데이터는 아니다.

그림자 영역의 깊이 자체가 체계적으로 틀리면 RANSAC도 잘못된 면을 만들 수 있다.
현재 처리는 RGB 때문에 면을 나누는 경로를 제거하지만, 잘못된 깊이가 지지하는 추가 후보는 남을 수 있다.
누락된 깊이나 가려진 면을 만들어 채우지 않는다. 따라서 해당 영역 전체를 원래 면에 복원했다고 해석하면 안 된다.
직각/평행 조건으로 측정값을 강제 보정하거나 H형강의 면 수를 강제하지 않는다.
현재 입력에는 카메라 confidence 채널이 없으므로 센서 신뢰도 기반 필터는 포함하지 않는다.
깊이 접힘의 연결 여부로 면을 강제 삭제하는 규칙은 실제 flange를 누락시켜 적용하지 않았다.
잡음이 심하거나 화면상 매우 얇은 면은 최소 면적 조건에서 제외될 수 있다.
그런 형상이 중요한 경우 일반 모드와 비교하고, 실제 사용 거리에서 치수·법선을 별도로 검증해야 한다.
