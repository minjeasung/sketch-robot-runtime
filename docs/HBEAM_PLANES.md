# H형강 평면 추출

`target_selector`는 `plane_structure=hbeam`을 기본값으로 사용한다.
시작 시 ROS 파라미터 `plane_structure=generic`으로 일반 평면 모드를 선택할 수 있다.
예: `ros2 run sketch_control target_selector --ros-args -p plane_structure:=generic`.
이 파라미터는 노드 시작 시 읽으므로 변경 후 노드를 다시 시작해야 한다.

## 처리 방법

1. 기존 RGB 직선 경계와 깊이 연결 영역을 유지한다. RGB가 깊이 프레임과 맞지 않으면 깊이만 사용한다.
2. 3×3, 5×5 깊이 이웃의 법선으로 RANSAC 후보를 보완한다. 색이 같거나 좁은 web과 flange의 접힘을 찾기 위한 단계다.
3. 반복 RANSAC에서 제외됐던 원래 점들도 모든 면 후보와 거리를 비교해 다시 배정한다. 먼저 찾은 면이 좁은 면의 점들을 계속 차지하지 않게 한다.
4. 충분한 연결 면적을 갖지 못한 후보는 경쟁 전에 제외한다. 복셀 축소 후 점이 부족한 작은 면은 원래 점으로 다시 피팅한다.
5. 급경사 면은 인접한 역깊이 변화가 이어지면 연결한다. 단순히 깊이 단절 임계값 전체를 높이지 않는다.
6. H형강 모드는 긴 면 주변의 짧은 잔여 조각을 추가로 억제한다. 같은 연결 영역의 긴 후보와 방향·거리 관계가 맞는 경우에만 적용한다. 방향이 뚜렷하게 다른 짧은 면과 평행한 깊이 단차는 유지한다.

일반 모드에도 법선 후보, 공동 점 배정, 연결성 검사, 급경사 연결 개선이 적용된다.
H형강 전용 잔여 조각 억제만 일반 모드에서 비활성화된다.
카탈로그 JSON의 `structure` 필드로 사용한 모드를 확인할 수 있다.

## 검증과 한계

`test_hbeam_planes.py`는 폭 16/24px web, 회전, 근거리, 부분 가림,
급경사 flange, 짧은 끝면, 평행 단차 및 실제 촬영 깊이 12프레임을 검증한다.
`test_target_rgb_pairing.py`는 실제 선택 콜백에서 H형강 모드와 카탈로그 출력을 확인한다.
기존 평면 추출 테스트는 색 줄무늬의 오분리 및 떨어진 면 사이의 잘못된 연결을 검사한다.

녹화 데이터의 ROI에는 세 철골 면과 왼쪽 전경 띠가 포함돼 네 후보를 기대한다.
물체 종류를 분류하거나 H형강 전체의 면 수를 강제하는 방식은 아니다.
H형강 모드의 잔여 조각 억제는 형상 가정에 기반한 휴리스틱이므로,
짧고 비슷한 방향의 별도 면이 중요한 다른 형상에는 일반 모드를 사용할 수 있다.

깊이가 실제로 없는 면이나 가려진 면을 만들어내지 않으며, 직각/평행 조건으로
측정값을 강제로 보정하지 않는다. 녹화 회귀 테스트의 면 수·지지점·피팅 잔차는
분할의 일관성을 확인하는 지표다. 실제 치수·법선의 절대 정확도를 보증하지 않는다.
최소 지지점과 최소 투영 폭 조건도 유지되므로 화면상 매우 얇은 면은 제외될 수 있다.
