# 현재 EOAT로 뿜칠 경로 실기 검증

`spray_motion_test`는 **실제 로봇 이동**을 수행한다. 뿜칠건이 미장착인 현재 EOAT
전용이며 분사 품질이나 실제 밸브 ON/OFF 타이밍을 검증하는 모드는 아니다.
ZED만으로 표면을 확정하고 노즐 기준 표면 이격 0.500 m를 사용한다. 롤러 반지름이나
접촉 오프셋은 더하지 않는다. 공구 축은 RB10 `-y`, RB20 `+z`가 바깥쪽 법선의 반대를 향한다.

## 실행

설치된 로봇 PC의 소스 폴더에서 실행한다. 다른 API가 8080을 사용하는 경우 아래처럼
별도 포트로 기동한다. 기존 로봇 제어 프로세스와 동시 제어하지 않는다.

```bash
SKETCH_PROFILE=spray_motion_test bash scripts/run_system_api.sh --port 8081
```

`config/sketch_runtime.env`가 있으면 그 파일의 설정을 먼저 확인한다.
관리 화면 `http://127.0.0.1:8081/`에서 실제 로봇 IP와
**EOAT 뿜칠 이동 검증 · 분사 OFF** 프로필을 확인한다.
서버 기동만으로 로봇이나 카메라 프로세스가 시작되지는 않는다.

## 검증 순서

기본 카메라 입력은 Outpost다. [Michelo 연동 안내](MICHELO_INTEGRATION.md)에 따라
ZED 스트리밍, 보정한 장치 ID·시리얼과 원본 IPC 접근을 먼저 준비한다.
D405의 장치 설명·보정·브리지·드라이버·refiner·perception TF는 요구하지 않는다.

1. `bash scripts/check_runtime.sh --real`로 설치를 확인한다.
   ZED가 실제 연결되어 있고 현재 장착에 맞는 보정값인지 확인한다.
   설치 스크립트의 패키지 확인은 공정별 카메라 준비 상태 판정과 별개다.
2. 현장 이동 공간과 비상정지를 확인하고 관리 화면에서 전체 시작한다.
   프로세스 RUNNING 외에 실제 관절 상태, 카메라 영상·점군, TF,
   controller와 실행기 준비 상태까지 확인한다.
3. 스케치 화면에서 `EOAT 이동 검증 · 실제 로봇 이동 · 50 cm 이격 · 분사 항상 OFF`
   표시를 확인한다. 이 프로필에서는 롤러 도장 전환이 잠긴다.
4. **① 대상 인식**에서 ZED 영상의 충분히 넓은 평면을 추출·선택한다.
5. ZED 대상 잠금과 표면 상태를 확인하고 **다음: 작업 지정**을 누른다.
   이 단계에서 D405 접근·촬영 이동은 없다.
6. **② 작업 지정**에서 활성 면의 ZED 정면 투영에 작업영역을 작게 설정·확정한다.
   사각형·닫힌 자유선·이어진 직선을 사용할 수 있다. 응답 후 **다음: 계획·실행**을 누른다.
7. **③ 계획·실행**에서 경로 방식을 **자동** 또는 **수동**으로 선택한다.
   수동은 자유선·직선으로 경로를 완성한 후, 자동은 확정 영역을 확인한 후
   공통 **계획 생성·검증**을 누른다. Settings는 서버 값 확인용이다.
   기본 분사 폭 0.350 m, 겹침 30%, 속도 0.020 m/s 및 노즐 기준 0.500 m 이격을 확인한다.
8. 경로 생성·계획 검사·실행 준비를 각각 확인한 뒤 **작업 시작**을 누른다.
   계획 검사는 경로·작업영역·공정 조건에 대한 검사이며, 이동 구간 검사는 실행 중 수행한다.
   용접의 전체 궤적 사전 계획 완료를 뜻하지 않는다. 작업 시작 이후 실제 로봇이 움직인다.
9. 성공 후 자동 생성된 여러 행과 행 사이 이동, 다른 평면의 활성화·경로 재생성을 검증한다.
   평면별 도포 경로 실행은 따로 수행한다. 실제 노즐 장착과 이격은 별도 실측한다.

응답 수신만으로 다음 단계로 이동하지 않는다. 탭 왕복은 계획을 유지하지만 경로 방식·입력 변경은 재검증을 요구한다. **작업 중단**은 모든 단계에서 사용할 수 있다.

## 유지되는 조건

- 시작 시 `real_painting_enabled=true`, `dry_run=false`,
  `painting_force_enabled=false`, `spray_motion_test=true`, `process_mode=spray`를 사용한다.
- 명시적인 `process_mode=paint`와 이 프로필을 함께 지정하면 설정을 거부한다.
- `spray_motion_test`는 읽기 전용 ROS 파라미터이며 프로필 변경은 전체 종료 후 가능하다.
- 일반 Spray 시작도 Paint로 바꾸려면 전체 종료 후 D405를 포함하여 다시 시작해야 한다.
- 건 ON 명령은 도포 획, 이동, 중단을 포함해 항상 차단된다. 모의 건 ACK는 발행하지 않는다.
- compliance OFF의 최신 상태와 힘 명령 OFF를 계속 요구한다.
  충돌 검사, 작업영역·계획 식별, 실측 관절 시작 상태, 로봇 인터록을 유지한다.
- F/T 영점·접촉 탐색·힘/토크 보정은 사용하지 않는다.
- 실제 분사 제어 시험은 건 어댑터 구현 후 일반 `work` 프로필의 뿜칠 모드로 별도 검증한다.

설치 점검과 오프라인 테스트 통과는 실제 로봇·카메라 검증 완료를 뜻하지 않는다.

### 중단 후 화면 복구

작업 중단 요청만으로 정지 완료로 표시하지 않는다. 기존 서버의 명시적 안전 해제
(`reset_execution_abort`) 후 새 IDLE 응답과 해제된 준비 상태를 확인하면 편집을 다시
허용하며, 중단 전 계획은 재사용하지 않는다. 서버 전체 재시작으로 복구했다면 로봇의
정지와 시스템 준비를 확인한 뒤 스케치 화면을 새로고침하고 대상을 다시 지정한다.
현재 도장·뿜칠 상태 메시지로는 재연결만으로 새 서버 세션을 판별할 수 없다.


## Isaac Sim · Spray v2 원뿔 기반 채우기

상용로봇 플랫폼의 Spray v2를 선택한 시뮬레이션은 원본 ROBOI EOAT v2 STEP의
`spray coat` 형상을 `assets/construct/spray_v2/envelope.json`으로 보존한다.
강체 공구·충돌 메시에는 분사 원뿔을 추가하지 않는다.

- 원본 형상: 길이 500 mm, 시작 반지름 3 mm, 끝 반지름 300 mm.
  원뿔 시작은 노즐 TCP보다 2 mm 뒤이며 축은 TCP +Z이다.
- 노즐–작업면 이격은 500 mm를 유지한다. 이 위치의 폭은 **602.376 mm**이다.
  원본 기울기를 유지해 CAD 끝단보다 2 mm 연장한 값이다.
- 자동 채우기는 작업영역의 긴 축을 따른다. 여러 획이면 폭의 10%가 겹치도록
  획 간격을 **542.1384 mm**로 유지한다. 폭을 한 획으로 덮으면 한 획만 생성한다.
- 획을 따라갈 때만 분사 표시를 켜고, 접근·획 사이 이동·종료·중단에는 끈다.
  영역 밖으로 분사 폭이 넘는 것은 경로 생성 거부 사유가 아니다.
  기존 로봇 충돌·도달성·계획 식별 검사는 유지한다.
- Isaac의 원뿔·현재 도포 영역·누적 도포 영역은 실제 시뮬레이션 노즐 자세로 계산하는
  **기하학적 표시**다. 도막 두께, 재료 유동, 실제 밸브 동작 검증은 아니다.
  시뮬레이션 표시 신호와 물리 뿜칠건 출력은 분리하며 이동 시험의 물리 분사 명령은 OFF다.

이 설정은 cone profile이 연결된 플랫폼 런타임에 적용한다. 위의 기존 실환경 이동 시험
프로필에 기록된 350 mm·30% 설정을 일괄 변경하지 않는다.
데모 대상은 H형 구조물의 두 기둥 사이 수평 부재 윗면이다. UI에서 해당 면을 추출하고
작업영역 확정 → 자동 채우기 → 계획 검사 → 작업 시작 순으로 진행한다.

### 2026-10-18 장착 ZED 시점 · 실제 UI 이동 재검증

상용 플랫폼·왼팔 Spray v2·오른팔 Hongik 용접/레이저·완전 시뮬레이션에서
실제 Chrome UI로 H형강 수평 부재 윗면 선택 → 작업영역 확정 → 자동 경로 생성 →
작업 시작을 수행했다. 두 번의 실행이 `COMPLETE`까지 도달했다. 데모 녹화는
사용자가 수행하며 이번 재검증에서는 영상을 녹화하지 않았다.

초기 자세에서는 접근 IK 분기 선택이 불안정했고, 다른 접근 성공 시에도 원래
공구 회전 자세의 획 중간에서 `left_manipulator_link4`와 `zed2i_link` 충돌로
전체 Cartesian 경로가 거절됐다. 원형 원뿔 프로필에 한해 노즐의 위치·분사 축·
500 mm 이격을 유지하는 축 회전 0°/180°와 두 IK 초기 추정값을 검사한다.
**접근 이동을 보내기 전에 전체 획과 종료 위치의 충돌 검사까지 통과한 후보만**
사용한다. IK 초기 추정값은 관절 이동 명령이 아니며, 접근과 실제 실행 구간의
기존 충돌 검사·시작 상태·계획 식별 검사는 유지한다.

### 2026-10-19 시험체 배치 변경

사용자 요청으로 상용 플랫폼·왼팔 뿜칠·완전 시뮬레이션의 H형강 전체를

`[-0.515, -1.9, 0]`으로 바뀐다. Isaac USD와 MoveIt 충돌 메시를 동일 변환으로

이전 날짜의 경로 실행 측정값은 이전 배치에 대한 결과이며, 새 배치에서는

같은 날 ZED가 이전 작업 위치를 내려다보는 문제를 수정했다. 장착 변환을 유지한 채
