# 현재 EOAT로 뿜칠 경로 실기 검증

`spray_motion_test`는 **실제 로봇 이동**을 수행한다. 뿜칠건이 미장착인 현재 EOAT
전용이며 분사 품질이나 실제 밸브 ON/OFF 타이밍을 검증하는 모드는 아니다.
롤러 바깥 접촉면 기준 법선 방향 0.500 m 이격과 기존 롤러 자세 규칙을 사용한다.

## 실행

설치된 로봇 PC의 소스 폴더에서 실행한다. 다른 API가 8080을 사용하는 경우 아래처럼
별도 포트로 기동한다. 기존 로봇 제어 프로세스와 동시 제어하지 않는다.

```bash
SKETCH_PROFILE=spray_motion_test bash scripts/run_system_api.sh --port 8081
```

`config/sketch_runtime.env`가 있으면 그 파일의 설정을 먼저 확인한다.
관리 화면 `http://127.0.0.1:8081/`에서 실제 로봇 IP와
**EOAT 뿜칠 이동 검증 · 분사 OFF** 프로필을 확인한다.
서버 기동만으로 로봇이나 카메라 프로세스가 시작되지는 않는다.

## 검증 순서

기본 카메라 입력은 Outpost다. [Michelo 연동 안내](MICHELO_INTEGRATION.md)에 따라
ZED/D405 스트리밍, 보정한 장치 ID·시리얼과 원본 IPC 접근을 먼저 준비한다.

1. `bash scripts/check_runtime.sh --real`로 설치를 확인한다.
   ZED와 D405가 실제 연결되어 있고 현재 장착에 맞는 보정값인지 확인한다.
2. 현장 이동 공간과 비상정지를 확인하고 관리 화면에서 전체 시작한다.
   프로세스 RUNNING 외에 실제 관절 상태, 카메라 영상·점군, TF,
   controller와 실행기 준비 상태까지 확인한다.
3. 스케치 화면에서 `EOAT 이동 검증 · 실제 로봇 이동 · 50 cm 이격 · 분사 항상 OFF`
   표시를 확인한다. 이 프로필에서는 롤러 도장 전환이 잠긴다.
4. ZED 영상에서 충분히 넓은 평면 하나를 추출·선택한다.
   **선택한 면 측정**은 실제 로봇을 움직인다. D405 광학 중심의
   법선 방향 0.32 m 이격, 광축 정렬, 측정 승인 결과를 확인한다.
5. 작업영역을 작게 설정하고 짧은 직선 하나로 경로를 생성한다.
   경로 미리보기, 이격과 자세, 충돌 없는 접근 경로를 확인한 뒤 작업 시작을 승인한다.
6. 성공 후 두 획과 획 사이 이동을 확인하고, 마지막으로 여러 평면의 측정 순서를 검증한다.
   평면별 도포 경로 실행은 기존처럼 따로 수행한다.

## 유지되는 조건

- 시작 시 `real_painting_enabled=true`, `dry_run=false`,
  `painting_force_enabled=false`, `spray_motion_test=true`를 사용한다.
- `spray_motion_test`는 읽기 전용 ROS 파라미터이며 프로필 변경은 전체 종료 후 가능하다.
- 건 ON 명령은 도포 획, 이동, 중단을 포함해 항상 차단된다. 모의 건 ACK는 발행하지 않는다.
- compliance OFF의 최신 상태와 힘 명령 OFF를 계속 요구한다.
  충돌 검사, 작업영역·계획 식별, 실측 관절 시작 상태, 로봇 인터록을 유지한다.
- F/T 영점·접촉 탐색·힘/토크 보정은 사용하지 않는다.
- 실제 분사 제어 시험은 건 어댑터 구현 후 일반 `work` 프로필의 뿜칠 모드로 별도 검증한다.

설치 점검과 오프라인 테스트 통과는 실제 로봇·카메라 검증 완료를 뜻하지 않는다.
